Первая неделя
Время пар в Excel

В исходных образцах время звонков различается. По умолчанию сохраняем время из Excel. Выгрузка охватывает три недели, начиная с выбранной даты.

Как разделяются недели

СверхуНечётная
СнизуЧётная

Разделение определяется по линии внутри ячейки, даже если половины разной высоты.

Общая ячейка без разделения — обе недели. Подгруппы учитываются отдельно.

PDF обрабатываются в твоём браузере.

Результат строится только по загруженным файлам. Занятия отсутствующих групп не восстанавливаются.
