# Личное расписание

Тестовый MVP: несколько PDF, выбор преподавателя, просмотр нечётной и чётной недели, выгрузка по приложенному шаблону Excel.

## Запуск

Node.js 22.16+ и npm. На Windows проверен Node.js 22.16.0.

```sh
npm ci
npm run dev
```

```sh
npm run build
node test-schedule.mjs "путь/к/251-251K-271-291-291K-206.pdf"
```

Статическая сборка находится в `dist/client`. Для её локального просмотра можно использовать любой HTTP-сервер. Не открывайте index.html через file://.

## Границы MVP

- Текстовые PDF формата исходного образца: пять дней, пять временных слотов, группы по колонкам.
- Верхний раздел ячейки — нечётная неделя, нижний — чётная; высота разделов может различаться.
- Отсутствие внутренней линии означает занятие на обеих неделях. Подгруппы разбираются внутри каждого раздела.
- PDF обрабатываются в браузере, без серверной загрузки и внешних API.
- Сохраняются все части исходного XLSX, кроме значений в трёх листах и названий недель при смене начальной чётности. Число листов, оформление, размеры, объединения, печать и примечания как элементы шаблона сохраняются. Старые занятия и текст примечаний очищаются.
- Выгрузка рассчитана на три недели. Даты вычисляются от заданного начала занятий. Праздники, замены и индивидуальные исключения из календаря автоматически не определяются.
- Названия предметов можно переименовать перед выгрузкой. Семантические сокращения не угадываются.
- Нераспознанные страницы и пересечения останавливают экспорт. Совместные занятия нескольких групп требуют отдельной поддержки.
- Проверены девять записей Бардина Д.П. из исходного PDF, случаи подгрупп, обеих недель, повторных загрузок, конфликтов и сохранение структуры шаблона. Проверены типы, сборка и линтер. Полный сценарий в браузере автоматизированно не проверялся.
- Необязательный WebMCP-интерфейс только читает уже извлечённые данные. Проверка в браузере с WebMCP не проводилась.
